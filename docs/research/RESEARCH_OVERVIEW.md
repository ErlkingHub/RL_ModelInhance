## 1. 研究定位与阅读入口

本项目研究：**通过 Reinforcement Learning 学习随剩余资源和候选集合变化的高层控制规则，驱动透明的逐步构造器求解 Multidimensional Knapsack Problem（MKP）**。网络的主要策略输出是状态级控制向量 θ，而非自由的逐物品神经评分。当前实现将二分图 Transformer、候选关系特征、固定评分基函数和剩余问题 LP 松弛结合起来，由 PPO 和训练期终局续行排序信号学习控制器。

当前能够确认的是这套机制已实现，并保存了一组可核算的 Chu 评估结果。**尚未证明性能主要来自高层学习，也未证明各模块有独立、稳定的增益。** 随着评分基函数和 LP 信息增强，底层虽仍无可训练参数，其规则能力也发生了变化。这是理解本项目创新论证时必须保留的边界。

## 2. 问题与研究价值

给定 N 个物品、M 种资源，利润为 $p_i\ge0$，资源消耗为 $w_{ij}\ge0$，容量为 $C_j>0$，目标是

$$
\max_{x\in\{0,1\}^{N}}\sum_{i=1}^{N}p_i x_i,
\qquad
\sum_{i=1}^{N}w_{ij}x_i\le C_j,\quad j=1,\ldots,M.
$$

顺序构造时，每一步只能从尚未选择且满足全部剩余容量的物品中选择。局部高利润或高密度物品可能耗尽关键资源，排除后续更好的组合。因此，“剩多少容量”与“剩余容量能换来什么利润”是两个不同的问题。MKP 为检验约束表征、资源机会成本和长期信用分配提供了明确的目标与可复核的可行性条件。问题及环境合约见 [mkp_data.py](../../mkp_data.py) 和 [mkp_env.py](../../mkp_env.py)。

本项目的长期目标是降低参考 gap，同时保留可审查的控制接口与构造过程。[README](../../README.md) 提出的接近或低于 **0.1%** 是研究目标；当前总体结果尚未达到该目标。参考值取自数据集的 best-known objective，没有在本仓库证明其全局最优性。

## 3. 五个核心科学问题

1. **高层策略的增量贡献**：同样的 LP、评分基函数和构造预算下，学习并动态更新 θ 比固定合法 θ、未训练初始 θ 或静态 θ 好多少？
2. **长期规划与局部启发式的边界**：θ 能否稳定改变关键决策及完整终局收益，还是主要复制当前密度、LP 和两物品兼容规则？
3. **约束感知的来源**：网络是否学习了资源之间的相对价值与竞争，还是主要受硬可行性掩码、人工关系特征和 LP 对偶先验驱动？
4. **控制接口是否足够且可学**：更好的动作能否由合法 θ 表达；若能，PPO 与排序监督为什么能够或不能学到并保持它？
5. **泛化与证据可重复性**：合成数据训练的收益能否在独立实例、不同 N、紧容量分层和多个训练种子上保持，同时计入实际计算成本？

这些问题的验证方案及优先级见 [开放问题](OPEN_RESEARCH_QUESTIONS.md)。它们比增加网络宽度或延长训练更直接影响研究结论。

## 4. 当前算法思想与技术路线

当前方法是一种受固定评分接口约束的 Hierarchical Policy：

**动态状态 → LP 与几何特征 → 二分图 Actor → 状态级 θ → 固定评分解码器 → 一个可行物品 → 更新状态。**

Actor 输出相对资源价格、收益与稀缺度指数、瓶颈/机会/余量惩罚、资源交互与搭配权重、两个 LP 权重及采样温度。θ 不随 N 增长，但资源交互部分随 M 二次增长。固定解码器将 θ 与无参数基函数组合为实际物品概率；训练采样物品，主评估逐步 greedy。Critic 使用独立网络，提供 PPO/GAE 的状态价值估计。详细公式及边界见 [算法设计](ALGORITHM_DESIGN.md)。

选择这一接口的研究动机是：把“资源价值随状态变化”的学习与“按规则保证可行的执行”分开，使研究者能够定位控制信号、候选排序和终局收益之间的联系；同时减少对物品数量固定输出维度的依赖。这是架构直觉，**不自动保证更好泛化、样本效率或解释忠实性**。相比自由逐物品策略，固定接口也可能无法表达某些有益排序。

当前 v6 每个状态求解剩余 MKP 的平滑 LP 对偶近似，以原始解近似、约化成本、影子价格及上界作为输入；θ 还直接控制 LP 评分项。解码器不执行整数分支、回溯或修复，但已获得优化结构先验。因而“无参数”不能作为“底层很弱”或“高层贡献主要性能”的实验依据。[mkp_lp.py](../../mkp_lp.py)、[mkp_Model.py](../../mkp_Model.py)、[mkp_basis.py](../../mkp_basis.py)。

长期反馈有两条路径：PPO 从完整轨迹利润学习；额外排序损失在相同状态下强制不同首动作，用更新前冻结策略续行估计终局差异。后者是训练期、当前策略条件下的标签，不能视为真实最优动作。LP 上界势函数整形在 γ=1、终止势能为零时只平移完整回报；是否降低 GAE 方差、改善学习仍待独立实验。[mkp_Trainer.py](../../mkp_Trainer.py)、[mkp_ranking.py](../../mkp_ranking.py)。

## 6. 当前进展与可靠结论

唯一在当前分支纳入 Git 的原始实验包是 [results/20261022_195937_430788](../../results/20261022_195937_430788/manifest.json)。本次从保存的逐实例表、选择序列与 MAT 数据复核，而未重新训练或执行模型评估。

| 项目 | 已保存证据 |
| --- | --- |
| 评估范围 | M=5/10，N=100/250/500，6 组各 30 例，共 180 例 |
| 主方法 | `learned_dynamic`，单轨迹 greedy，未启用 sampled best-of-K |
| 总体 mean signed gap | **0.30992636%**，相对数据集 best-known reference |
| ≤0.1% 的比例 | **44/180，24.44%**，不能由总体均值代替 |
| 最差 gap | **1.59354389%** |
| 可行性 | 180 个保存解可行，独立重算容量违约为 0 |
| 泛化范围 | 记录训练 N=100；N=250/500 共 120 例被标记为跨规模，M5/M10 各用自己的模型 |
| 收敛诊断 | 两个来源训练均为 `not_converged`，最终 update=2000；被测 best update 分别为 625/1175 |

该结果说明此配置在这一批实例上能够构造可行解，且存在跨 N 的冻结评估记录。它不能证明多种子稳定性、跨 M 泛化、方法优于所有 Baseline，或高层动态控制、LP/排序/组合模块分别贡献了多少。已有 checkpoint SHA，但对应权重和来源完整训练日志未纳入当前 Git 快照，不能仅凭此实验包重跑模型。

负面发现也构成进展：总体未达到 0.1%；紧容量 N=100 仍然困难；较高资源利用率不能消除利润配置误差；默认评估删除了 fixed/static 对照，因此当前证据不能回答高层净贡献。历史改动所声称的 gap 降低，多数缺原始文件，不能组成可信排行榜。完整统计与缺口见 [实验发现](EXPERIMENTAL_FINDINGS.md)。

## 7. 尚未解决的问题与下一阶段重点

首先固定 v6 的数据、解码公式、θ 范围、训练预算、checkpoint 选择规则和评估口径，补齐 **同一 LP 底层上的控制器贡献对照**。其次区分表达受限与学习失败，使用独立实例的同状态诊断，观察首动作、冻结续行收益和更新后实际收益；不能只看标签损失或 θ 幅度。随后将 LP 特征、LP 评分和整形分开做匹配消融，并在多个训练种子上验证。实验进入正式大预算前，应预先登记指标、选择规则和预算。

跨规模研究应保留 N=100 与 N=250/500 的分层解释；tight-ratio、M/N 和尾部 gap 应与总体均值并列报告。若长期重复观察 Chu 并据此调整架构，应将其明确记为研究反馈，后续增加独立最终测试集；代码不读取 Chu 训练并不能证明整个研究过程没有测试集适应。

## 8. 长期维护与不可静默改变的基线

- 保留“高层控制器＋透明固定评分解码器”的当前研究基线。学习型逐物品评分、搜索、修复或新的 Solver 应作为明确命名的新实验臂，不能混入原方法。
- 保存 signed gap 的百分数口径、best-known reference 的性质、单轨迹与多轨迹预算区别，以及按独立实例统计的原则。
- 训练与 checkpoint 选择保持合成数据边界；变更数据分布、验证选择或 θ 范围必须记录配置和新标识。
- 其他分支的 checkpoint schema 数字可能相同但语义不同，至少联合检查 controller/decoder 标识与模型配置。
- 新结论须同时更新实验发现、证据索引和开放问题；附 commit、数据/权重 SHA、种子、预算和结果路径。未提供证据时保留“待验证”。
